## Why China advanced faster

China's production collectors, article storage, processing and renderer already form an active path. Other desks often collect successfully but intentionally retain originals privately, then require source-specific rights, explicit processing, signed handoff, public projection and delivery. English AFP/NSC avoid translation but still face source-grounding/quality checks. Korean HWPX and Indonesian QA introduce real extraction/translation risks. Singapore is constrained by actual permissions; Japan has access/format and component-grant limits; U.S. reference families are currently metadata products. These are different bottlenecks, not eight missing scrapers.

## Selected implementation phase

Objective: make the existing AFP/NSC/Kemhan public-safe handoff distinguish failed refresh from successful input, without blocking unrelated sources or losing previously admitted records. Stop at a reviewed engineering PR; production verification needs a separately authorized release.

Before: a failed, timed-out, oversized or malformed download printed a line, exited successfully and left any older local family file available for admission. This was a code-proven latent recovery defect; this audit did not find evidence that a production runner actually consumed a stale local file. Fetch errors also had no post-delivery health-gate signal.

After: remove the prior local family input before refresh (including policy-disabled families); reject malformed/nonobject JSON; atomically install fetched bytes. Return fixed source dispositions, emit safe warnings/summary and an existing-step failure count. The existing final health gate notifies after unrelated delivery. Signature, source/version, policy and allowed-field checks remain in `admit()`. Failed fetches do not withdraw accepted DB rows or authorize processing. No workflow is added.

Changed code: `scripts/fetch_daily_machine_outputs.py`, existing `.github/workflows/daily_update.yml`, and `tests/test_fetch_daily_machine_outputs.py`. Existing workflows #950/#953 also edit Daily; integrate the small fetch-step/health additions deliberately when those branches land.
